# HELP FILE

## Menu

1 - Insert Line
Adds a new line at a specified position.

Example:
Enter Line Number: 2
Enter Text: Hello World

----------------------------

2 - Delete Line
Deletes the specified line.

Example:
Enter Line Number: 3

----------------------------

3 - Display Document
Displays all lines with line numbers.

----------------------------

4 - Search Word
Searches for a word in the document.

Example:
Enter Word: C

----------------------------

5 - Find & Replace
Replaces a word with another.

Example:
Old Word: Hello
New Word: Hi

----------------------------

6 - Save File

Example:
notes.txt

----------------------------

7 - Load File

Example:
notes.txt

----------------------------

8 - Document Statistics

Shows:
- Total Lines
- Total Words

----------------------------

9 - Undo

Restores the document before the last modification.

----------------------------

10 - Exit

Closes the program.
