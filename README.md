## Project Description
This project is a command-line Line Editor developed in C. It allows users to create, edit, search, save, and load a text document line by line.

## Features

### Core Features
- Insert Line
- Delete Line
- Display Document

### Bonus Features
- Search Word
- Find & Replace
- Save File
- Load File
- Line Count
- Word Count
- Undo Last Action

## Project Structure

```
main.c

```

## Compilation

```bash
gcc main.c editor.c file.c utility.c -o line_editor
```

## Run

### Windows

```bash
line_editor.exe
```

### Linux

```bash
./line_editor
```
